
# MVP Online Shop

Это учебный проект full-stack разработчика, выполненный без AI


## Технический стек
В проекте используется Next.js + FastAPI + aiogram бот + PostgreSQL 
## Описание проекта
#### Функциональность
 Пользователь на сайте и в tg боте может просматривать каталог товаров, фильтровать, сортировать их, добавлять в корзину, созадвать заказ + авторизация, просмотр заказов (отображается статус заказа)
#### Сущности
- Товар 
- Категория
- Пользователь
- Заказ
